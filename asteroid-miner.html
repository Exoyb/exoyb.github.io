// about-this-project

This one started before the portfolio did.

Asteroid Miner has been an ongoing personal project for longer than this portfolio has existed. I was already building, changing and breaking it before I had somewhere public to document the work.

Putting it here did not mark the start of the game. It marked the point where I cleaned up the project, prepared a browser-compatible build and gave it a proper place to live. From here, the playable build and patch notes can grow together instead of the game being hidden away on my own PC.

// what-is-it

The game

Mine asteroids, haul ore and manage progression across runs. The current build includes ore unlocks, upgrades, perk drafting, persistent saves and meta progression, with the project still very much being something I intend to keep changing.

Context

Asteroid Miner already existed before I built this portfolio. V1 is not the first version of the game itself; it is the first version I have cleaned up, packaged and published as a playable browser project here. I wanted people to be able to actually play it rather than just read about it or look at screenshots.

$ cat changes.log

Release

  • Prepared the existing Godot project for a browser release using the Compatibility renderer.
  • Exported the game as a Godot Web/WebAssembly build for GitHub Pages.
  • Kept the editable Godot source project private and published only the compiled browser build.
  • Added an explicit launch step so the large runtime is not downloaded unless somebody actually chooses to play.
  • Added restart, fullscreen and exit controls around the embedded game.
  • Established this patch-note history so future game changes can be documented against the same live build.
$ cat outcome.txt

Outcome

  • Asteroid Miner now has a single live browser build that can be updated in place.
  • The rest of the portfolio stays lightweight until somebody actively chooses to launch the game.
  • Future releases can focus on new game content and patch notes instead of rebuilding the website integration each time.
