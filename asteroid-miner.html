About the game

Asteroid Miner (working title btw) is a game where you enter a dystopian world trying to make a living. You have leased a spaceship off of EverGrowth Dynamics™, a dystopian corporate entity that is fleecing you with ever-increasing lease and rental payments.

Destroy asteroids, collect minerals, upgrade your ship and see if you can pay off your ever-growing debt to EverGrowth Dynamics™. Each time you pay a bill, you'll get a reward to buff your ship for that run!

  • Unlock the Black Market
  • Unlock new ores like Iron, Unobtainium and more
  • Unlock thrusters and abilities
  • Explore different colour palettes with F6
  • Earn post-game currency for permanent upgrades
  • Visit the Skill Tree shop

More about the project

The extra bits, the broken bits, the things I learned and the things I still want to add.

What is "Asteroid Miner", anyway? I hear you ask

Asteroid Miner is a WIP pet project of mine for fun. It predates my portfolio here, and it has been both challenging and rewarding to build.

I understand this isn't cybersecurity, far from it, but it's still an accomplishment I'm proud of.

Is the balancing good? No.

Is the gameplay addictive? Probably not.

Most importantly though... is it FUN?

Because... that's also a No...

But!... is it MINE? Abso-bloody-lutely it is.

I hope you enjoy it. It's far from finished. Please give it a go.

Future ideas
  • Space Pirates! Yarr, ye' need to be payin' a fine otherwise prepare to be boarded! - Pay a fine, or fight to the death
  • Character portraits
  • New ships and weapons
  • Additional ores
  • Buy different colour palettes, perhaps the colour palettes unlock additional ores you couldn't see before?
Issues
  • Balancing - the game is far too easy. I'm still trying to work out the maths and the overall 'feel' - challenging & addictive vs cosy & satisfying.
  • UI scaling - the UI scales poorly and is lacking assets. It's mainly made up of placeholders at the moment.
  • Colour palettes - the UI doesn't correctly swap colour palettes.
  • Visual bugs - flickering asteroid textures and shading issues with certain colour palettes on asteroids and background space junk.
What did I learn?
  • Some GDScript
  • Godot 4
  • Troubleshooting... lots and lots and lots of troubleshooting and debugging
  • More troubleshooting. Especially around performance and optimisation.
  • The importance of backups, as my laptop died and I lost about 40-60 hours of work
  • Pixel art in Aseprite
  • Ableton and Serum 2 for sound design, mixing, EQ and sound effects
  • GitHub + Godot + Web exports
  • Save states, permanent / temporary / session memory

Context

Asteroid Miner already existed before I built this portfolio. V1 is not the first version of the game itself; it is the first version I have cleaned up, packaged and published as a playable browser project here. I wanted people to be able to actually play it rather than just read about it or look at screenshots.

$ cat changes.log

Release

  • Prepared the existing Godot project for a browser release using the Compatibility renderer.
  • Exported the game as a Godot Web/WebAssembly build for GitHub Pages.
  • Kept the editable Godot source project private and published only the compiled browser build.
  • Added an explicit launch step so the large runtime is not downloaded unless somebody actually chooses to play.
  • Added restart, fullscreen and exit controls around the embedded game.
  • Established this patch-note history so future game changes can be documented against the same live build.
